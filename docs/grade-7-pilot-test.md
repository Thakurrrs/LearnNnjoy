# Grade 7 interactive-adventure pilot test

## Purpose

Check whether a learner can discover and explain a Grade 7 idea through an activity, without being coached, timed, ranked, or compared with anyone else.

## Who to invite

- 5–8 Grade 7 learners, one at a time.
- Use a nickname only. Do not record names, school details, photographs, or contact details.
- Let the learner choose any one adventure first.

## Facilitator introduction

Say: “This is not a test of you. We are testing whether the activity makes sense. Please say what you notice. If something is confusing, that helps us improve it.”

Do not explain the mathematics before the learner tries the activity.

## Run one 8–12 minute session

1. Ask the learner to choose one adventure from the map.
2. Observe silently while they explore. Only answer questions about buttons or navigation.
3. When they reach the short discovery check, ask: “Why did you choose that answer?”
4. Ask one transfer question after completion, using a fresh situation:
   - Mountain Rescue: “You are at +2 and move down 5 levels. Where are you?”
   - Balance Lab: “If a box plus 3 blocks equals 10 blocks, what is in the box?”
   - Smart Shopper: “What would a 25% discount mean for ₹100?”
   - Skatepark Architect: “What changes when an angle gets wider?”
   - Cricket Data Room: “How could you find the highest value in a different bar chart?”
5. End by asking, “What would you change so this activity is easier to understand or more fun?”

## Record only these anonymous observations

| Signal | Record |
|---|---|
| Independent start | Yes / needed navigation help |
| Core interaction | Understood / confused / skipped |
| Discovery check | Correct independently / correct after retry / not yet clear |
| Transfer question | Explained / partly explained / not yet clear |
| Engagement | Wanted another adventure / neutral / wanted to stop |
| Learner wording | One short anonymous quote, if useful |

## Decision rule before scaling

Improve an activity before reusing its pattern when either of these happens:

- Fewer than 4 of 5 learners explain the central idea independently or with a single retry.
- Two or more learners misunderstand the same control, picture, or instruction.

Do not add longer video to solve a confusing activity. First make the interactive model, labels, and feedback clearer. Add a short story animation only if it gives essential context that the activity cannot provide alone.
